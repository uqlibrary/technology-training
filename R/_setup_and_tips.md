## Keep in mind

- Everything we write today will be saved in your project. If you are using a Library computer, remember to save it on your H drive or USB stick.
- R is case sensitive: it will tell the difference between uppercase and lowercase.
- Respect the naming rules for objects (no spaces, does not start with a number...).

For any dataset or function doubts that you might have, don't forget the  ways of getting help in Positron:

1.  the shortcut command: `?functionname`
2.  the help function: `help(functionname)`
3.  the keyboard shortcut: press <kbd>F1</kbd> after placing your cursor on a function name
4.  the popup: hover over a function name

## Essential shortcuts

Remember some of the most commonly used Positron shortcuts:

* execute from script: <kbd>Ctrl</kbd> + <kbd>Enter</kbd>
* assignment operator (`<-`): <kbd>Alt</kbd> + <kbd>-</kbd>

## Setting up

Let's open Positron and get set up. (If you don't have it installed already, follow [installation instructions](../installation.qmd).)

### New project folder

-   Select New (top left) and choose "New Folder from Template"
-   Select "R Project" from the available templates
-   Enter a name for your project, for example "dplyr_intro"
-   Choose the folder where you want to create the project, such as `Documents/RProjects`, which you can create if it doesn't exist yet
-   Leave the default options selected unless instructed otherwise
-   Click "Create"

### Create a script

We will use a script to write code more comfortably.

-   Create a new file by selecting File > New Text File, or press:
    -   <kbd>Ctrl</kbd>+<kbd>N</kbd> (Windows/Linux)
    -   <kbd>Cmd</kbd>+<kbd>N</kbd> (Mac)
-   Save the file by selecting File > Save, or press:
    -   <kbd>Ctrl</kbd>+<kbd>S</kbd> (Windows/Linux)
    -   <kbd>Cmd</kbd>+<kbd>S</kbd> (Mac)
-   Navigate to your project folder and save the file as "process.R"
